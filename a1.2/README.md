# FIT5032 A1.2 — UrbanCanopy Melbourne

Vue 3 application for a fictional Melbourne not-for-profit focused on urban greening, tree planting and biodiversity.

## A1.2 requirements demonstrated

- Vue 3 Composition API with modular single-file components
- Responsive layouts for mobile, tablet, desktop and wide screens
- Dynamic project data rendered from JavaScript objects
- Project search and type filtering using Vue reactive state and computed values
- Volunteer registration with required, email-format, numeric-range and consent validation
- Clear inline validation feedback and accessible form relationships
- Local Storage persistence for successful registrations

## Run locally

```sh
npm install
npm run dev
```

## Production check

```sh
npm run build
```

## Suggested demonstration

1. Resize the application across mobile, tablet and desktop widths.
2. Search for a suburb and filter projects by type.
3. Select a project and open the volunteer form.
4. Submit invalid values to demonstrate multiple validation types.
5. Correct the values and submit to show the saved confirmation.
